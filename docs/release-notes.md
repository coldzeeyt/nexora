Nexora is a free Windows browser for the Nexora community network.

Includes tabs, bookmarks, history, light/dark appearance, free accounts, recovery codes, a visual website builder, HTML/CSS/JavaScript editing, ZIP uploads, isolated live previews, published versions, network search, moderation, Freq and Solo Live.

Addresses work inside Nexora. This installer is an unsigned preview release; publisher signing is not configured. Email recovery is unavailable; save your private recovery code. Hosting uses the owner's existing Railway plan; users are not charged.
